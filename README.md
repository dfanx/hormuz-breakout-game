🚢 Strait Breakout：霍爾木茲突圍戰
《霍爾木茲突圍戰》 是一款快節奏的 2D 動作閃避遊戲。玩家將扮演一名勇敢的油輪船長，在波斯灣局勢緊張的封鎖線中，試圖保護珍貴的貨運資源並航向自由的海域。

📖 故事背景
中東油雲密佈，霍爾木茲海峽已成為美方與伊朗對峙的前線。作為全球能源命脈的守護者，你必須操作滿載貨櫃的油輪，在重重封鎖與導彈威脅下尋找生存空間。這不僅僅是航行，更是一場關於反應與決策的生存考驗。

🎮 遊戲特色
極簡戰鬥手感：受經典閃躲遊戲啟發，強調流暢的物理移動感與即時回饋。

物理化受損系統：油輪僅有 3 個貨櫃（血量），每次受撞擊都會真實看到貨櫃掉落大海，容錯率低，節奏緊湊。

動態威脅機制：

美軍與伊朗巡邏艇：高速俯衝與夾擊。

武裝砲艇：精準的直線砲擊，帶有淡色預瞄線。

區域導彈：1.5 秒縮圈預警，考驗瞬間定位能力。

強力增益道具：

🛢️ 無敵油桶：2 秒無敵並進入加速衝刺模式。

⚡ 電磁強砲：發射高能束清除前方一切障礙。

💳 川普金卡：傳說級道具，瞬間清空全屏敵方單位。

手動靈敏度校準：內建校準系統，玩家可依據裝置螢幕與個人習慣調整最佳滑動手感。

8-bit 復古沉浸：完全由 Web Audio API 即時合成的電子音樂與音效回饋。

⌨️ 操作說明
電腦版 (PC)
移動：使用鍵盤方向鍵 ↑ ↓ ← → 或 W A S D。

手機版 (Mobile)
移動：在螢幕上任意位置滑動即可引導油輪方向。

校準：若感覺轉向太滑或太慢，請使用首頁的「手動校準」功能微調靈敏度。

🛠️ 技術架構
這是一個純前端的開發作品，展現了單一檔案架構下的高效能邏輯處理：

核心語言：Vanilla JavaScript (ES6+)。

渲染引擎：HTML5 Canvas 2D API。

音效系統：Web Audio API (OscillatorNode & GainNode 即時合成)。

樣式框架：Tailwind CSS (用於 UI 佈局)。

適配性：支援 Responsive Design，針對行動裝置進行了物件縮放與靈敏度優化。
